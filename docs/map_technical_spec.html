맵 생성 & 오브젝트 풀링 메커니즘

오브젝트 풀링 (Object Pooling) MapManager.cs

런타임 프레임 드랍 및 가비지 컬렉션(GC) 부하를 최소화하기 위해 맵 청크(MapChunk)를 파괴하지 않고 재활용합니다.

Pool Structure:
Dictionary<GameObject, Queue<GameObject>> mapPools
Queue<GameObject> activeMaps
  • 시작 시 initialChunkPoolSize 만큼 미사용 맵 미리 비활성화 생성
  • 화면 밖으로 지나간 맵 청크는 activeMaps.Dequeue() 후 풀로 반환
셔플백 (ShuffleBag) 무작위 생성 Fair Randomness

// MapManager.cs - 0.5 grid 정렬 유틸리티
private float SnapToHalfGrid(float value)
{
    return Mathf.Round(value * 2f) / 2f;
}

// 다음 맵 위치 계산
float nextX = nextSpawnPosition.x + chunkWidth;
nextSpawnPosition = new Vector3(SnapToHalfGrid(nextX), SnapToHalfGrid(nextSpawnPosition.y), 0f);
정밀한 타일 갭 방지: 맵 청크가 연속 배치될 때 소수점 오차로 인한 빈틈(Seam)이 생기지 않도록 모든 스폰 좌표를 0.5 Grid 단위로 Snap 정렬합니다.

2.5D Parallax 원근감 & 카메라 연출

Parallax 스크립트 기반 원근감
카메라: Orthographic (Z축 = 0 고정)
x 오프셋: distX = camMoveDistance.x * (1 - parallaxEffectX)
y 오프셋: distY = isYTracking ? camMoveDistance.y * (1 - parallaxEffectY) : 0
  • 0에 가까울수록 원경 (카메라를 그대로 따라감)
  • 1에 가까울수록 근경 (월드 좌표에 고정됨)
  • 1보다 크면 전경(Foreground) 효과 연출
카메라 바운더리 & Blend (화면 튐 방지)

플레이어가 새로운 청크로 진입 시 Cinemachine 바운더리를 부드럽게 전환합니다.

  • MapChunkBoundaryTrigger: 플레이어 진입 감지
  • 듀얼 Cinemachine 카메라 또는 0.5초 Ease In Out Blend를 적용하여 화면 튐(Snap) 완벽 방지
Parallax Y축 제어 코드
// Parallax.cs - LateUpdate 물리 이동 연산
private void LateUpdate()
{
    Vector3 camMoveDistance = cam.position - startCamPos;
    bool isYParallaxActive = (mapManager != null 
                              && CameraConfinerManager.Instance != null
                              && CameraConfinerManager.Instance.IsYTrackingActive);

    float distX = camMoveDistance.x * (1 - parallaxEffectX);
    float distY = isYParallaxActive ? camMoveDistance.y * (1 - parallaxEffectY) : 0f;

    transform.position = new Vector3(startPos.x + distX, startPos.y + distY, transform.position.z);
}

페이즈별 난이도 스케일링 & 스폰 규칙

3단계 논리적 페이즈 (CurrentLogicalPhase) 진행 구조
페이즈 진행 시간 난이도 디자인 중심축 주요 기믹 및 맵 변화
Phase 1 0 ~ 60초 수량적 스케일링 (Introductory) 평지 중심, 가시 함정(SpikeTrap) 및 기본 몬스터 밀도 증가. Y축 카메라 고정.
Phase 2 60 ~ 120초 피지컬 액션 컨트롤 (Mechanical) 복합 이동 플랫폼 패턴(대각/수직), SlowPad 발판 및 관성 컨트롤 필요. Y축 카메라 추적 활성화.
Phase 3 120초 이상 복합 기믹 시너지 (Complex Synergy) 이동 플랫폼 위 공중 몬스터 전투, landing zone 촉수(Tentacle) 스폰, 타이밍 가시 회피 등.
스폰 금지 영역 (Exclusion Zone Compliance): 상자(Chest)나 몬스터 스폰 시, 플레이어 스폰 지점 주변 마진 및 함정/점프대 바로 위 영역은 스폰 가능 대상에서 엄격히 제외(Exclusion Zone)되어 플레이어의 불합리한 사망을 방지합니다.
